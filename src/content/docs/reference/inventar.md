**Rozsah:** Global launch / Season 1, rešerše 12. října 2026. Komunitní podklady, nikoli naše měření v klientu. Ceny a limity porovnej s aktuálním tooltipem nebo panelem hry.

## Který sklad použít

| Místo | Komu patří | Použití |
| --- | --- | --- |
| <span id="ref-cube">**Cube**</span> | Aktuální postavě. | Inventář, který nosíš u sebe; podle klientských dat 40 základních slotů. |
| <span id="ref-character-storage">**Character Storage**</span> | Jedné postavě. | Osobní sklad, 25 základních slotů. Bere i předměty vázané na postavu, které Server Storage odmítne. |
| <span id="ref-server-storage">**Server Storage**</span> | Postavám stejného serveru podle způsobilosti předmětu. | Přesuny povolených věcí mezi postavami; 25 základních slotů. |
| <span id="ref-shop-storage-mail">**Shop Storage / Mail**</span> | Podle konkrétní odměny. | Přečti příjemce ještě před vyzvednutím. |
| <span id="ref-legion-storage">**Legion Storage**</span> | Legii a nastaveným oprávněním. | Nezaměňuj ho s osobním či serverovým skladem. |

Server a Character Storage rozšiřuješ po řádcích (5 slotů) za Kina; ceny obou skladů jsou stejné, platí se zvlášť a každý další řádek je dražší. Za Kina dojdeš na 180 slotů; podle klientských dat je strop 400 slotů s vouchery. Cube má deset rozšíření za Kina, celkem asi 2,7 milionu.

## Bound není jediná odpověď

Tooltip odděluje osobní obchod, prodej na Marketu, serverový/legion sklad a vázání po nasazení. Některé Bound věci mohou do Server Storage, jiné ne: podle klientských dat tam projdou například lektvary, scrolly a Power Shards, ale ne Resurrection Spiritstone, Odyle Energy, Soul Codex, Key: Hidden Cube ani skiny. Pravidlo jednoho předmětu proto nepřenášej na celou kategorii a čti tooltip.

Crafting, Material Conversion, Supply Requests a Enhancement čerpají materiály přímo z Character Storage, bez vybírání. Remote Storage (otevření skladů odkudkoli) je služba členství; u NPC Storage Manager je přístup zdarma.

## Co se sdílí

Členství platí pro postavy na serveru, kde ho aktivuješ; Quna, A2 Mileage a Daeva Pass patří konkrétní postavě. Poštu pro účet (account mail) vyzvedne jen jedna postava účtu, ne každý alt zvlášť. NC 3. října oznámila, že titul, skiny, pet a křídla z Founder's Packu budou po opravě fungovat na všech postavách účtu; do té doby platí původní pravidla, aktuální stav ověř v klientu.

Při převodu serveru (server transfer) zůstává na starém serveru obsah Server Storage, pošta, nabídky na Marketu a sloty postav. Rozšíření Server Storage se přenášejí. Poštu proto vyzvedni předem.
