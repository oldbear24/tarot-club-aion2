## Najdi výraz z tooltipu nebo party chatu

Český slovník používá názvy ze hry. Hráčské zkratky mohou mít mimo AION 2 jiný význam; tabulka je redakční vysvětlení běžného použití.

| Výraz / alias | Český význam |
| --- | --- |
| <span id="ref-gs-gear-score-item-level">**GS / Gear Score**</span> | Celková úroveň výbavy postavy, v anglických návodech často „item level“ postavy. Sčítá Item Level nasazených kusů a další příspěvky (Enhancement, utracené Daevanion body, řádky kamenů, Arcana); slouží jako vstupní podmínka obsahu. Složení vysvětluje [GS průvodce](../../pruvodce/gs-progrese/#co-přidává-gs-a-co-především-cp). |
| <span id="ref-item-level-predmetu">**Item Level předmětu**</span> | Úroveň jednoho kusu výbavy, například True Dragon Lord 62. Je jen jednou složkou celkového GS. |
| <span id="ref-cp-combat-power">**CP / Combat Power**</span> | Souhrnný ukazatel statů; není měření skutečného DPS. |
| <span id="ref-ap-abyss-points">**AP / Abyss Points**</span> | Měna Abyss rozvoje a příslušných obchodů. |
| <span id="ref-kina-kinah">**Kina / Kinah**</span> | Herní peníze. Rozlišuj obchodovatelnou a Bound variantu. |
| <span id="ref-dps">**DPS**</span> | Poškození za sekundu; hráči tak označují i roli zaměřenou na poškození. |
| <span id="ref-burst">**Burst**</span> | Krátké okno soustředěného poškození. |
| <span id="ref-sustain">**Sustain**</span> | Dlouhodobé udržení života, zdrojů nebo výkonu. |
| <span id="ref-uptime">**Uptime**</span> | Doba aktivního působení bonusu nebo útočení na dostupný cíl. |
| <span id="ref-proc">**Proc**</span> | Aktivace dodatečného efektu, často podmíněná nebo náhodná. |
| <span id="ref-cc-crowd-control">**CC / Crowd Control**</span> | Omezení akcí či pohybu protivníka. |
| <span id="ref-cleanse-dispel">**Cleanse / Dispel**</span> | Cleanse odstraní negativní efekt ze spojence nebo z tebe, Dispel zpravidla odstraní pozitivní efekt z cíle. Co přesně jde odstranit, určuje popis schopnosti. |
| <span id="ref-cc-break-stun-break">**CC break / Stun break**</span> | Schopnost nebo akce pro zrušení omezení, ze kterého se lze uvolnit. |
| <span id="ref-dot-damage-over-time">**DoT / Damage over Time**</span> | Poškození rozložené v čase. |
| <span id="ref-hot-heal-over-time">**HoT / Heal over Time**</span> | Léčení rozložené v čase. |
| <span id="ref-aoe-area-of-effect">**AoE / Area of Effect**</span> | Plošný účinek místo zásahu jediného cíle. |
| <span id="ref-cooldown-cd-cdr">**Cooldown / CD / CDR**</span> | Čekání na další použití / jeho zkracování. |
| <span id="ref-stagger-break">**Stagger / Break**</span> | Vyprázdnění bossova stagger ukazatele; liší se od obyčejného CC. |
| <span id="ref-stagger-check">**Stagger check**</span> | Mechanika vyžadující dostatečný stagger v časovém okně. |
| <span id="ref-aggro-threat-enmity">**Aggro / Threat / Enmity**</span> | Pozornost protivníka a její získávání. |
| <span id="ref-taunt">**Taunt**</span> | Schopnost, která na tebe převede pozornost protivníka. Samotná role tanka aggro nezajistí. |
| <span id="ref-stack-soak">**Stack / Soak**</span> | Sejít se na značce / společně rozdělit zásah podle mechaniky. |
| <span id="ref-spread">**Spread**</span> | Rozestoupit se, aby se osobní zásahy nepřekrývaly. |
| <span id="ref-kite">**Kite**</span> | Vést pronásledující útok nebo protivníka po bezpečné trase. |
| <span id="ref-telegraph">**Telegraph**</span> | Vizuální nebo zvukové varování před útokem. |
| <span id="ref-enrage">**Enrage**</span> | Konec povoleného času nebo fáze s výrazně silnějším bossem. |
| <span id="ref-wipe">**Wipe**</span> | Neúspěšný pokus končící smrtí skupiny. |
| <span id="ref-guard">**Guard**</span> | Výbavový slot vedle hlavní zbraně; nezaměňuj ho s názvem hráčské role. |
| <span id="ref-specialty">**Specialty**</span> | Volitelná úprava aktivní schopnosti, navázaná na její úroveň. |
| <span id="ref-stigma">**Stigma**</span> | Samostatně rozvíjená schopnost se svými sloty a body. |
| <span id="ref-claim-reward-cube-infusion">**Claim / Reward Cube / Infusion**</span> | Vyzvednutí dungeonové odměny / její objekt / vložení Odyle pro odměnu. |
| <span id="ref-odyle-odyle-energy">**Odyle Energy**</span> | Energie, kterou platíš za vyzvednutí odměny z dungeonové truhly. Obnovu a strop vysvětluje [Dungeony a Odyle](../../pruvodce/dungeony-odyle/#jak-hospodařit-s-odyle). Odyle ze sběru je jiná položka, crafting materiál. |
| <span id="ref-insight">**Insight**</span> | Úroveň rozvoje: Pet Insight peta (nejvýše 3 úrovně) nebo Genus Insight rodové desky (10 úrovní). Viz [Pets](../pets/). |
| <span id="ref-pity-guaranteed-reward">**Pity / Guaranteed Reward**</span> | Garantovaný výběr po splnění počítadla konkrétní aktivity. |
| <span id="ref-enhancement-amp">**Enhancement / Amp**</span> | Běžné úrovně vylepšení (+) / další stupně Amplified Enhance u způsobilé výbavy. |
| <span id="ref-soul-bind-sync-transfer">**Soul Binding / Soul Sync / Transfer**</span> | Zvyšování hodnot řádků výbavy pomocí Soul Codex / přerolování jednoho řádku pomocí Sync Stone / přenos investice na nový Unique kus. Pravidla jsou v [Enhancement a Transfer](../../pruvodce/vylepsovani-vybavy/). |
| <span id="ref-substance-morph">**Substance Morph**</span> | Přeměna předmětu podle receptu na jiný předmět, například sealed wing na křídla, Odyle na rudu nebo Unique drop na Transfer či Sync Stone. Recepty najdeš v [Materiálech](../materialy/) a [Wings](../wings/). |
| <span id="ref-upcraft">**Upcraft**</span> | Výroba vyššího tieru z crafted kusu o stupeň nižšího. Podle klientských dat vždy uspěje a přenese Enhancement, Amp a Soul Binding; viz [Crafting](../crafting/). |
| <span id="ref-bound">**Bound**</span> | Omezení manipulace uvedené na předmětu; neznamená samo o sobě všechna omezení skladu. |
| <span id="ref-owned-equip-effect">**Owned / Equip Effect**</span> | Bonus vlastnictví / bonus aktuálně nasazeného kusu. |
| <span id="ref-main-alt">**Main / Alt**</span> | Hlavní / další postava. |
| <span id="ref-bis-best-in-slot">**BiS / Best in Slot**</span> | Nejlepší kus pro konkrétní slot, build a podmínky; není univerzální vlastnost barvy. |
| <span id="ref-rng">**RNG**</span> | Náhodnost výsledku. Průměrný počet pokusů není garance. |
