## Snížení a vyhnutí se poškození

| Stat | Co dělá |
| --- | --- |
| **Defense** | Omezuje příchozí poškození. |
| **Evasion** | Šance vyhnout se zásahu; tooltip uvádí strop, viz [Limity a sporné hodnoty](../limity/). |
| **Block** | Podporuje parry nebo blok štítem; výsledek ovlivňuje Accuracy a Block Penetration útočníka. |
| **Damage Tolerance** | Snižuje přijaté poškození a působí proti Damage Boost útočníka. Stejně fungují varianty Weapon, Critical, PvE a Boss. |
| **Endurance** | Šance na poloviční poškození; proti Endurance Penetration. |
| **Regeneration** | Šance obnovit část utrpěného poškození jako HP; proti Regeneration Penetration. |

Endurance a Regeneration jsou aktivované efekty, nikoli jistota u každého zásahu.

## Léčení

:::note[Důležité: poskytované a přijaté léčení se liší]
**Heal Boost** posiluje poskytované léčení, **Incoming Heal** léčení přijaté. Nelze je zaměnit za stejný bonus. Konkrétní přínos pro schopnost ověřuj s jejím tooltipem a aktuální výbavou.
:::

## Obnova a pohyb

| Stat nebo rodina statů | Význam |
| --- | --- |
| **Combat Natural … Regen** | Pravidelná obnova daného zdroje během boje. |
| **Out-of-Combat Natural … Regen** | Obnova mimo boj. |
| **HP Potion Recovery** | Zlepšuje množství HP získané z lektvaru. |
| **MP Gain increase** | Posiluje obnovu MP schopnostmi. |
| **MP Cost** | Cena schopností v MP; záporný bonus snižuje náklady. |
| **Stamina** | Zdroj pro sprint a úhyby. |
| **Flight Power** | Zdroj spotřebovávaný při letu. |

Náhodný proc Regeneration se liší od pravidelné obnovy **Natural HP Regen**. Při sestavování výbavy rozlišuj oba názvy.

## Co zlepšit, když často umíráš

Doporučení Tarot Clubu:

1. Zaznamenej příčinu smrti: jednorázový zásah, několik rychlých zásahů nebo postupné ubývání HP.
2. Nejprve zkontroluj mechaniku a pozici. Výbava sama neřeší špatně načasovaný úhyb.
3. Pro opakované pokusy porovnej nejen přežití, ale také ztrátu poškození a dostupnost léčivých schopností.
4. V partě se domluv, kdy použít obranné a léčivé cooldowny. Překrytí všech najednou může vytvořit mezeru později.

Navazuje [Výbava a rozumné upgrady](../../pruvodce/vybava/).
