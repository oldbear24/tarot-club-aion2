## Jak tabulku číst

Vedle šestice základních atributů se setkáš se staty pojmenovanými po empyreanských bozích. Komunitní data pro Global popisují nižší převody než některé KR/TW návody.

Níže je výklad dvojic efektů z dat Wikily; přesný převod není vlastní měření Tarot Clubu.

| Stat | Podporované efekty |
| --- | --- |
| **Justice [Nezekan]** | Defense increase + Perfect Chance |
| **Destruction [Zikel]** | Attack increase + Perfect Resist |
| **Freedom [Vaizel]** | Accuracy increase + Evasion increase |
| **Death [Triniel]** | Critical Hit increase + Regeneration Penetration |
| **Illusion [Kaisinel]** | Snížení cooldownu + Endurance Penetration |
| **Wisdom [Lumiel]** | Snížení MP Cost + Double Chance |
| **Life [Yustiel]** | HP increase + Regeneration |
| **Destiny [Marchutan]** | MP increase + Endurance |
| **Time [Siel]** | Combat Speed + Double Resist |
| **Space [Israphel]** | Move Speed + Block increase |

V této datové sadě má každý uvedený efekt převod **0,1 % za bod**; u cooldownu a ceny MP jde o snížení. Light [Ariel] a Darkness [Azphel] zde nemají uvedené sekundární převody.

## Dva efekty, dvě různé potřeby

### Kde body získávat

Global podklady popisují Pantheon s **jedním Colossus slotem, čtyřmi Statues a dvanácti Artworks**. Příběh poskytuje základní colossus a sochy; další kusy pocházejí z achievementů, bossů, dungeonů a obchodů. Konkrétní kus může mít podmínku nákupu — například dokončení požadovaného Nightmare bosse.

Božské staty získáváš také z [Arcana](../../pruvodce/arcana/). Nezaměňuj tedy menu Pantheon s jediným zdrojem těchto atributů. Podobně pojmenované [Daevanion desky](../../pruvodce/daevanion/) jsou další samostatný systém.

**Doporučení Tarot Clubu:** nejdřív zkontroluj obsazení odemčených slotů a již získané příběhové kusy. Potom porovnávej celou dvojici statů náhrady. Cena další sochy má smysl až ve vztahu k tomu, co nahradí.

### Jak dvojici vyhodnotit

Doporučení Tarot Clubu: při výběru si u každé dvojice napiš, který efekt skutečně využiješ. Dva bonusy na papíře nemusí znamenat dvojnásobný přínos pro tvůj způsob hraní.

Nesčítej automaticky všechny procentní bonusy jako finální zvýšení DPS. **Increase** základní hodnoty a **Chance** aktivace popisují jiné věci.

## Pozor na starší kalkulačky

Pokud kalkulačka pracuje s jiným regionem nebo patchem, její výsledky neber jako hodnoty Global. Při rozporu porovnej konkrétní stat v klientu před přidáním bodu a po něm. Screenshot obou hodnot je vhodný podklad pro opravu wiki.
